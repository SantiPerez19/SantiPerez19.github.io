# Portafolio — Santiago Pérez Cáñez

Portafolio personal de Santiago Pérez Cáñez, estudiante de Ingeniería en Sistemas de Información. Publicado como página de GitHub Pages en [SantiPerez19.github.io](https://SantiPerez19.github.io).

## Tecnologías usadas

| Tecnología | Uso |
| ---------- | --- |
| HTML5 | Estructura semántica del sitio (`nav`, `main`, `section`, `footer`). |
| CSS3 | Todo el diseño y la responsividad. |
| Google Fonts | Tipografías *Fraunces* e *Instrument Sans*. |
| GitHub Pages | Despliegue estático del sitio. |

### Detalles del diseño con CSS3

- **Variables CSS (`:root`)** para gestionar la paleta de colores y el radio de las tarjetas.
- **CSS Grid** para la sección "¿Quién soy?" y la cuadrícula de proyectos.
- **Flexbox** para la navegación, listas de habilidades y el pie de página.
- **Media queries** para adaptar el diseño a dispositivos móviles (`max-width: 760px`).
- **`prefers-reduced-motion`** para respetar la preferencia del usuario de reducir animaciones.
- **`backdrop-filter`** para el desenfoque del menú fijo.
